## 實作選擇

- 維持一個 Cargo 工程及 `LiToModern` 現行主程式，預設 x64；歷史候選不作玩家主入口。
- 初期以已有 CPU RGBA 參考合成器／Win32 DIB 建立可比較像素結果；之後可加入 GPU renderer，資源解碼和遊戲狀態不依賴 GPU。
- PAK 偏移及長度計算使用 u64，原始欄位維持規定的 u8／u16／u32；HWND／指標與 LPARAM 使用原生寬度，不將位址存成 u32。网络欄位不能因 x64 而改長。
- 使用唯讀 archive handle、明確資源命名空間與載入預算；不大量複製遊戲資源，不按目錄順序猜重名圖檔。現行建置關閉 incremental，避免每輪累積大型資料夾。
- SPR／TIL 保留覆蓋資訊和 alpha；黑色不一律等同透明。未知壓縮、SP2／SPX／特效型別明確拒絕，附來源診斷。
