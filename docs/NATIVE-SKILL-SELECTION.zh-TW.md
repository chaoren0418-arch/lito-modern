# 原生技能選擇與世界選點

這一階段在目前 Windows x64 原生視窗加入已學會技能的下拉選單與施放按鈕。選單來自正式 S1E／S1F 技能集合，選取與施放是兩個操作；F1 治癒、F2 護盾、F3 光箭仍可使用。治癒可對目前目標或自己施放，護盾固定自己，光箭要求有效目標。其他已學會技能以編號列出「尚未支援」，不產生請求。

## 權威與輸入

`native_skill_selection::Model` 保存技能編號，新增／移除較前面的清單項目不會把選擇轉移到其他技能。已選技能移除後清空選擇，再加入也不自動恢復。連線 epoch、世界 generation、位置校正、施法者 object ID／incarnation 任一變更都使選擇失效；返回大廳／結算後清空模型。

目標保存 object ID、incarnation 與世界 generation。目標移除、死亡或同 ID 重新生成，治癒／光箭都拒絕舊選取，治癒不會因此偷偷轉向自己；明確沒有選取目標時才使用自己。護盾本來就是自身技能，忽略其他選取。

選擇模型只產生意圖；`LoginController::cast` 仍負責真實傳輸、施法／攻擊等待、動作完成及 reuse 門檻。HP／MP／學會清單及距離在送出前重新驗證；沒有本地扣魔、冷卻推算或傷害權威。真正 ClientSession 的 heal／shield／bolt／bolt-refused 探針也走此模型，回執另外記錄每次送出的技能編號、目標、連線與世界身分。

Win32 下拉選單與按鈕保有自己的方向鍵／空白鍵操作；點回世界後才由方向鍵移動、Space 持續攻擊。焦點離開世界、切換技能、施法、取消或世界身分變更時清除持續輸入。Esc 在世界清除目標與選點，在下拉選單保留原生操作。

## 同畫面選點

Frame 保留繪製特效所使用的地圖投影與相機位置，`ground_cell` 使用相同反算函式，檢查畫布 800×600、u16 座標與已載入 LTmap sector 邊界。世界 generation、地圖、施法者 incarnation／移動／動作狀態不符合時拒絕舊 Frame。地面選點只記錄與顯示座標，不發送座標技能。

物件點選另要求相同 visual revision；視窗記錄已畫出的 Frame 時間／revision 與 viewport，縮放、DPI／世界切換或新 Frame 尚未畫出時不採用舊命中矩形。選取後仍會在施放前驗證目標身分。

## 驗證界線

新增七項 Rust 檢查：技能 ID 穩定性與移除、不變 owner／變更 owner、完整已學會集合與不支援技能、正式 C14 向量及權威不變、目標替換／死亡／離場、即時 MP／HP／學會與距離變更、真實資源 Frame 的地面反算與失效選取。

最終 Rust／正式隔離 TCP／原始資源像素回歸及 EXE／JAR／原始碼雜湊，以 `驗證紀錄/current/native-skill-selection/summary.json` 和 schema19 current-build-receipt 為準。Release 只進行 compile check。沒有把編譯與模型檢查當成視窗操作、DPI／IME、音效裝置或玩家人工驗收。

目前只有三種技能可施放；技能圖示／快捷列綁定、其他攻擊技能、C14 地面技能、持續地面物件與完整 buff／冷卻／特殊中斷仍未完成。地面選點基礎不代表火牆或生命之泉已能使用。
