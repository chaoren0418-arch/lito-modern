# 原生場景封存單次觀測

schema37限定驗證：同一正式JAR下，Debug AMD64 EXE通過194 Rust／38組、54隔離TCP、93獨立像素及66 owner表比對；Release另通過六個正式戰鬥情境和原資源像素切片。GUI、音效裝置及完整玩法仍待驗收。

LTtile與LTsprite的IDX／PAK共四個封存，改用受限、拒絕write/delete sharing的同一控制代碼觀測大小和完整SHA256，再由持有該控制代碼的解析器讀取。索引仍逐筆驗證所有名稱、padding、重複、界限和長度；不略過未使用的錯誤。觀測到的四個角色及pin須與場景計畫完全相等。既有外部pin的load_static API維持原驗證路徑；取消及預算仍生效。

首輪回歸中，拒絕地面技能的權威、MP與伺服器結果正確，但探針在7張影格停止，未達原有10張驗證門檻。已讓探針在結果確認後補足觀測、最多等待10秒，重新驗證每個地面技能案例至少10張。原失敗證據保留於ground-floor-first-failure。

另一次完整回歸的房間切換探針曾達到90秒截止時間；相同EXE、JAR和來源的單項重跑通過。根因未定，首次日誌與重跑結果保留於cycle-first-failure。

六個相同正式隔離場景的Release場景準備中位數，由3700.865ms降至2022.010ms；場景準備加首張渲染中位數由5222.968ms降至3491.653ms。所有首張世界RGBA與前一版Release及本版Debug一致，權威攻擊次數一致。測量依序執行、OS快取未清除，僅作本機診斷，不保證即時幀率。Release的其餘正式TCP分支、GUI/IME/DPI和音效裝置尚未驗收。
